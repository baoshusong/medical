01

摘要 · Abstract

随着 CT 设备空间分辨率的物理限制，薄层或低剂量扫描常面临体素各向异性与细节丢失。 本文介绍 SwinIR-Med——一个面向 CT 影像的面内（2D）超分辨率重建工作站。 系统以 Swin Transformer 为骨干，对任意尺寸的轴位切片执行 4× 超分（128×128 → 512×512 patch 推理后拼接），在保持 Z 轴帧数的同时， 将输出体数据的 X/Y 像素间距缩小为原始的 1/4。

工作站基于 Qt6 Widgets 与 C++17 构建，集成 DCMTK 解析与 ONNX Runtime 推理，提供三平面 MPR 查看、窗宽窗位、 测量标注与重建前后对比。在代表性 CT 体数据上，相较于双三次插值，SwinIR-Med 在 PSNR / SSIM 上取得可量化的提升（详见第 04 节）。

03

方法 · Method

SwinIR-Med 采用 Swin Transformer 骨干，对单张轴位切片执行面内超分。

3.1 网络结构

给定低分辨率轴位 patch x ∈ ℝ^{128×128}，浅层特征提取器 F₀ = H_SFE(x) 获得浅层表征；随后由 N 个 Swin Transformer 残差块构成的深层特征提取模块 F_D = H_DF(F₀) 建模长程依赖与局部纹理；最后经 上采样模块（PixelShuffle，×4）与重建卷积得到高分辨率输出 ŷ = H_REC(F_D) ∈ ℝ^{512×512}。

3.2 损失函数

训练采用像素级 L₁ 损失为主，辅以感知损失约束，优化目标为 ℒ = ‖ ŷ − y ‖₁ + λ·ℒ_perc， 其中 y 为对应的高分辨率真值切片。

3.3 推理与拼接

对完整切片以 128×128 不重叠（边缘填充）切分，逐 patch 调用 ONNX Runtime 推理， 将 512×512 patch 拼接后裁剪为原始尺寸 4 倍，写回新 DicomVolume， X/Y 像素间距同步缩小为 1/4。
